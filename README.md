## 2. Self-Correcting SQL AI Agent
**Applied AI** | Google Gemini, Python, SQL, BigQuery, SQLGlot

An agent that lets business teams ask questions in plain English and get answers straight from the database.

1. **Translate:** Gemini turns the question into a BigQuery SQL query.
2. **Validate:** SQLGlot checks the syntax before anything touches the live database.
3. **Self-correct:** if BigQuery returns an error, it is fed back to Gemini to rewrite and retry, up to 3 attempts.
4. **Answer:** results are turned back into a plain-English response.
